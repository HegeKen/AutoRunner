为提升方案审核通过率并确保服务质量与用户体验，请开发者在提交方案时务必包含以下核心要素（*具体请见方案示例*）：

1. 接入场景简介
2. 场景节点全集（其中自动展开节点标明）、节点通知出现时机
3. 各场景节点的展示内容
4. 大岛、小岛、岛展开态、焦点通知卡片UI示意
5. 状态栏（OS2）、息屏UI示意
6. 焦点通知卡片、岛的展示时长

# 一、小米超级岛方案展示逻辑介绍

本节为您说明小米超级岛的展示机制与兜底策略，涵盖服务上岛优先级、兜底存在时长等逻辑，为方案设计提供系统化交互参考。

1. 上岛场景通常按照触发时间的先后进行优先级排序：新通知＞老通知
2. 岛展开态默认展开5s后收起
3. 若未设置消失逻辑，则触发兜底逻辑：岛默认1小时消失；通知卡片默认12小时消失
4. 通知栏焦点通知卡片无数量限制，平铺展示无折叠
5. 小折叠/背屏手机无需单独适配，由小米侧自行适配
6. 拖拽分享支持分享至：微信、QQ、短信、浏览器；分享内容：建议“文案+链接”，例如“我正在使用XX打车+URL”
